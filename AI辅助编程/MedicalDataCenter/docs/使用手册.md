# 医疗数据中心使用手册

## 1. 手册范围

本文档面向当前项目的实际可用能力，覆盖以下业务域：

- 数据源连接管理
- ETL 抽取与标准化
- 数据集与样本预览
- 报表设计、发布、导出、调度
- 开放 API 与第三方接入
- 系统管理与安全运维

适用角色：

- 平台管理员
- 数据工程师
- 报表设计师
- 第三方接入人员

## 2. 角色说明

| 角色 | 典型职责 |
| --- | --- |
| 平台管理员 | 用户、角色、权限、参数、安全配置、审计查看 |
| 数据工程师 | 数据源接入、ETL 配置、字段绑定、运行排查 |
| 报表设计师 | 模板设计、草稿保存、发布、导出、调度 |
| 第三方接入方 | OAuth2 取 token、调用开放 API |

## 3. 登录与首页

### 3.1 登录入口

推荐访问方式：

- 生产化演示入口：`https://mdc.localtest.me:18443/`
- 开发版入口：`http://127.0.0.1:18081/`
- 默认管理员账号：`admin / Admin@123`

登录成功后，系统会返回：

- `accessToken`
- `refreshToken`
- 当前用户展示信息
- 权限码列表

当前已支持：

- 自动会话续期
- 服务端退出登录
- 最小密码策略
- 连续失败锁定与审计记录

首次无法登录时，优先检查：

- 是否使用了最新入口地址
- 浏览器 `localStorage` 中是否残留旧 `mdc-token`、`mdc-user`
- 前后端容器是否已按最新镜像重建

### 3.2 工作台

登录后工作台会基于权限码动态装载菜单。当前主导航已覆盖：

- 工作台
- 数据源
- ETL
- 数据集
- 报表设计
- 报表任务
- 开放 API
- 系统管理

## 4. 数据源管理

对应页面：`/data-sources`

### 4.1 新增数据源

1. 点击“新增数据源”
2. 选择数据源类型
3. 填写连接地址、数据库名、用户名、密码
4. 点击“测试连接”
5. 测试通过后保存

当前已支持：

- 新增、编辑、删除
- 测试连接
- 启用/停用
- 敏感密码加密存储

建议：

- 演示时优先使用 `TiDB` 或 `MySQL`
- 停用中的数据源不要继续挂到新增 ETL 任务

## 5. ETL 抽取与标准化

对应页面：`/etl`

### 5.1 创建任务

1. 选择来源数据源
2. 选择抽取方式：全量或增量
3. 配置源表或自定义 SQL
4. 选择目标主题
5. 配置字段绑定
6. 保存并执行

### 5.2 当前主题范围

当前项目已覆盖以下标准主题：

- `cdm_patient`
- `cdm_encounter`
- `cdm_lab`
- `cdm_lab_result`
- `cdm_medication_order`

其中：

- `cdm_patient`、`cdm_lab_result`、`cdm_medication_order` 已形成 ETL 标准闭环
- `cdm_encounter`、`cdm_lab` 已用于开放 API 和报表展示

### 5.3 字段绑定模型

当前 ETL 已从历史分散字段切换到语义化绑定模型：

- 前端使用 `fieldBindings`
- 后端主存储使用 `etl_job.field_bindings_json`
- 历史 `idField/nameField/...` 仍保留用于兼容旧记录

这意味着新增主题时，前后端不需要继续堆叠一批硬编码字段分支。

### 5.4 运维建议

- 全量任务建议夜间执行
- 增量任务建议配置稳定游标字段
- 失败任务应回查运行记录和 checkpoint，避免重复入仓

## 6. 数据集管理

对应页面：`/datasets`

数据集页用于为报表和开放 API 提供统一入口。当前已支持：

- 数据集列表查看
- 字段元数据查看
- 样本数据预览
- 多主题样例展示

当前已覆盖数据集：

- `cdm_patient`
- `cdm_encounter`
- `cdm_lab`
- `cdm_lab_result`
- `cdm_medication_order`

## 7. 报表设计与任务

对应页面：

- 设计器：`/reports/designer/:id`
- 任务页：`/reports/jobs`

### 7.1 新建报表模板

1. 进入报表设计器
2. 选择数据集
3. 添加指标卡、表格、折线图、柱状图、饼图等组件
4. 在画布中调整组件布局
5. 在属性面板配置标题、绑定、样式和显隐
6. 配置筛选条件
7. 配置模板级参数
8. 保存草稿或直接发布

### 7.2 当前设计器能力

当前设计器已支持：

- 模板保存
- 24 栅格布局
- 组件排序、复制、删除、显隐切换
- 结构化 `bindings`
- 结构化 `interactions`
- 模板级 `parameters`
- 在线预览
- `PDF/Excel` 导出
- 草稿/发布双态
- 模板版本信息展示

### 7.3 模板参数

模板参数用于声明运行时输入，当前支持：

- 参数编码
- 显示名称
- 目标字段
- 操作符
- 默认值
- 必填约束

运行时输入会统一进入：

- 在线预览
- 导出
- 调度
- 快照追溯

### 7.4 发布与版本治理

当前模板已支持：

- 草稿保存
- 发布
- `draftVersion`
- `publishedVersion`
- `effectiveVersion`
- 基础乐观锁冲突校验

建议流程：

1. 在设计器编辑模板
2. 保存草稿
3. 预览并确认参数、筛选、联动结果
4. 点击发布
5. 再创建或更新调度任务

### 7.5 预览与导出

当前预览、导出和调度使用同一套模板解析逻辑。预览摘要中会显示：

- 布局列数
- 组件数量
- 筛选摘要
- 参数摘要
- 绑定摘要
- 联动摘要

导出建议至少验证：

- 一次 `PDF`
- 一次 `Excel`
- 一次带参数的预览

### 7.6 调度与快照

报表任务页当前支持：

- 新建调度
- 编辑调度
- 启用/禁用
- 手动执行
- 查看最近执行时间
- 查看下一次执行时间
- 查看绑定模板版本
- 查看快照列表

当前调度链路特性：

- 已启用任务自动注册到 Quartz
- 服务重启后自动恢复
- `report_schedule.template_version` 会记录绑定模板版本
- `report_snapshot.template_version` 会记录执行版本
- 若调度绑定版本与模板当前生效版本不一致，会直接阻断执行

## 8. 开放 API 使用

对应页面：`/open-api`

### 8.1 客户端申请

1. 管理员创建客户端
2. 分配作用域
3. 获取 `client_id/client_secret`
4. 通过 OAuth2 申请 token

推荐入口：

- 生产版：`https://mdc.localtest.me:18443/oauth2/token`
- 开发版：`http://127.0.0.1:18081/oauth2/token`

### 8.2 当前开放主题

当前已开放：

- 患者：`/open-api/v1/patients`
- 就诊：`/open-api/v1/encounters`
- 检验：`/open-api/v1/labs`
- 用药：`/open-api/v1/medications`
- 报表：`/open-api/v1/reports`

### 8.3 当前特性

当前开放 API 已支持：

- `OAuth2 + JWT`
- JSON 请求与 `Basic + form-urlencoded` 双入口
- 关键筛选参数
- 默认脱敏
- 限流
- 访问日志
- 统一成功日志口径 `ok rows=<n>`

### 8.4 联调建议

调用真实主题时，建议同时核对：

- 接口返回条数
- 是否已脱敏
- `requestId`
- `api_access_log` 是否记录 `ok rows=<n>`

## 10. 常见业务流程

### 10.1 新增一个数据接入任务

1. 配置数据源
2. 测试连接
3. 新建 ETL 任务
4. 配置字段绑定
5. 运行任务
6. 到数据集页确认样本结果

### 10.2 新增一个统计报表

1. 选择数据集
2. 配置组件布局和绑定
3. 配置筛选和模板参数
4. 保存草稿
5. 预览
6. 发布模板
7. 新建导出或调度任务

### 10.3 开放给第三方系统调用

1. 创建客户端
2. 分配作用域
3. 申请 token
4. 调用开放 API
5. 检查日志和限流情况

### 10.4 当前推荐验收顺序

1. 登录首页
2. 校验数据源新增和测试连接
3. 至少执行一次 ETL 任务
4. 在报表设计器创建一个带参数模板
5. 验证预览、发布、导出、调度
6. 调用患者、就诊、检验、用药开放接口
7. 在系统管理完成用户、角色、参数三类写操作

## 11. 使用注意事项

- 生产版请优先使用 `https://mdc.localtest.me:18443/`
- 生产环境必须替换默认密钥和默认密码
- 若会话失效，请重新登录；退出登录后旧 token 不可复用
- 抽取任务上线前必须完成样例数据验证
- 报表模板发布前必须确认参数、筛选和联动结果正确
- 调度版本不一致时会被阻断，这是当前设计的保护行为
- 页面行为异常时，可先清理浏览器 `localStorage` 后重试
