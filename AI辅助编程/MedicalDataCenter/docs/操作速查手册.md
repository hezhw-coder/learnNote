# 医疗数据中心操作速查手册

## 1. 说明

本文档汇总当前项目最常用的 Docker Compose 运维命令。所有命令默认在项目根目录执行：

```powershell
E:\trae_learning\MedicalDataCenter
```

## 2. 开发版

### 2.1 启动并构建

```powershell
docker compose -f .\docker\docker-compose.yml up -d --build
```

### 2.2 启动已有容器

```powershell
docker compose -f .\docker\docker-compose.yml start
```

### 2.3 停止服务但不销毁容器

```powershell
docker compose -f .\docker\docker-compose.yml stop
```

### 2.4 查看状态

```powershell
docker compose -f .\docker\docker-compose.yml ps
```

### 2.5 查看日志

```powershell
docker compose -f .\docker\docker-compose.yml logs -f backend
docker compose -f .\docker\docker-compose.yml logs -f frontend
```

### 2.6 停止并删除容器

```powershell
docker compose -f .\docker\docker-compose.yml down
```

### 2.7 常用访问地址

- 前端管理台：`http://127.0.0.1:18081/`
- 管理端 API：`http://127.0.0.1:18080/api`
- 健康检查：`http://127.0.0.1:18080/actuator/health`
- Swagger：`http://127.0.0.1:18080/swagger-ui.html`
- OAuth2 Token：`http://127.0.0.1:18081/oauth2/token`
- 开放 API：`http://127.0.0.1:18081/open-api/v1`

## 3. 生产版

### 3.1 启动并构建

```powershell
docker compose -f .\docker\docker-compose.prod.yml --env-file .\docker\.env.prod up -d --build
```

### 3.2 强制重建

```powershell
docker compose -f .\docker\docker-compose.prod.yml --env-file .\docker\.env.prod up -d --build --force-recreate
```

### 3.3 启动已有容器

```powershell
docker compose -f .\docker\docker-compose.prod.yml --env-file .\docker\.env.prod start
```

### 3.4 停止服务但不销毁容器

```powershell
docker compose -f .\docker\docker-compose.prod.yml --env-file .\docker\.env.prod stop
```

### 3.5 查看状态

```powershell
docker compose -f .\docker\docker-compose.prod.yml --env-file .\docker\.env.prod ps
```

### 3.6 查看日志

```powershell
docker compose -f .\docker\docker-compose.prod.yml --env-file .\docker\.env.prod logs -f backend
docker compose -f .\docker\docker-compose.prod.yml --env-file .\docker\.env.prod logs -f frontend
```

### 3.7 停止并删除容器

```powershell
docker compose -f .\docker\docker-compose.prod.yml --env-file .\docker\.env.prod down
```

### 3.8 常用访问地址

- 前端管理台：`https://mdc.localtest.me:18443/`
- HTTP 跳转入口：`http://127.0.0.1:18081/`
- 健康检查：`https://mdc.localtest.me:18443/actuator/health`（仅部署机本机）
- OAuth2 Token：`https://mdc.localtest.me:18443/oauth2/token`
- 开放 API：`https://mdc.localtest.me:18443/open-api/v1`

注意：

- 生产版不要使用 `http://127.0.0.1:18080/actuator/health`
- 因为生产编排里 `backend` 未映射宿主机端口，且 Nginx 仅允许本机访问 `/actuator/`

## 4. 常用组合命令

### 4.1 全部停止

```powershell
docker compose -f .\docker\docker-compose.yml stop
docker compose -f .\docker\docker-compose.prod.yml --env-file .\docker\.env.prod stop
```

如需排查生产版初始化卡住，可补充查看：

```powershell
docker compose -f .\docker\docker-compose.prod.yml --env-file .\docker\.env.prod logs --tail=200 tidb-init
```

### 4.2 全部启动

```powershell
docker compose -f .\docker\docker-compose.yml start
docker compose -f .\docker\docker-compose.prod.yml --env-file .\docker\.env.prod start
```

### 4.3 全部查看状态

```powershell
docker compose -f .\docker\docker-compose.yml ps
docker compose -f .\docker\docker-compose.prod.yml --env-file .\docker\.env.prod ps
```

### 4.4 仅重建前后端

开发版：

```powershell
docker compose -f .\docker\docker-compose.yml up -d --build backend frontend
```

生产版：

```powershell
docker compose -f .\docker\docker-compose.prod.yml --env-file .\docker\.env.prod up -d --build backend frontend
```

## 5. 快速排查

### 5.1 `.env.prod` 找不到

```powershell
cd E:\trae_learning\MedicalDataCenter
docker compose -f .\docker\docker-compose.prod.yml --env-file .\docker\.env.prod ps
```

### 5.2 查看生产版最近 200 行日志

```powershell
docker compose -f .\docker\docker-compose.prod.yml --env-file .\docker\.env.prod logs --tail=200 backend
docker compose -f .\docker\docker-compose.prod.yml --env-file .\docker\.env.prod logs --tail=200 frontend
```

### 5.3 用 curl 检查生产版入口

```powershell
curl.exe -k https://mdc.localtest.me:18443/
curl.exe -k https://mdc.localtest.me:18443/actuator/health
curl.exe -k https://mdc.localtest.me:18443/oauth2/token
```

## 6. 命令区别

- `stop`：只停止服务进程，容器和卷保留
- `start`：启动已存在的容器
- `down`：停止并删除容器和网络
- `up -d --build`：重新构建并后台启动
- `up -d --build --force-recreate`：强制重建容器，适合配置或证书变化后刷新环境
