# 后端接口与业务实现 Skill

用于处理控制器、服务层、认证鉴权、参数校验、数据库访问、任务调度和业务规则实现。

## 适用场景

当出现以下情况时调用：

- 用户要求新增或修改后端接口
- 任务涉及业务规则、权限控制、数据库读写
- 需要设计请求响应结构、错误码和校验逻辑
- 需要处理登录、令牌、限流、审计、调度等后端能力

## 推荐工作流

1. 确认接口目标、调用方和权限要求
2. 定义请求模型、响应模型和错误语义
3. 梳理服务层职责和依赖关系
4. 落地数据访问与事务边界
5. 加入鉴权、校验、日志和异常处理
6. 补充接口测试或集成验证

## 设计原则

- 控制器只负责协议转换和参数接入
- 业务规则尽量放在服务层
- 数据访问要避免重复 SQL 和过度耦合
- 错误响应要可预测、可观测
- 权限规则要与前端权限码保持一致

## 常见检查项

- 是否放行公共接口
- 是否错误使用 `403` / `401` / `400`
- 是否遗漏 CORS、CSRF、JWT 或过滤器影响
- 是否遗漏数据库迁移或初始化数据
- 是否需要审计日志和操作记录

## 验收清单

- 接口路径、方法、参数正确
- 正常响应与异常响应都可解释
- 权限链路可工作
- 数据写入与读取一致
- 日志和错误定位足够清晰
