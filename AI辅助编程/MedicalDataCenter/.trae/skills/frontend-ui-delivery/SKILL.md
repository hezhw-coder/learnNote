# 前端页面与交互 Skill

用于处理前端页面、组件、状态管理、表单、路由、可视化和交互体验相关任务。

## 适用场景

当出现以下情况时调用：

- 用户要求新建或改造前端页面
- 任务涉及组件拆分、表单交互、表格、图表、布局或主题
- 需要梳理路由、权限菜单、状态管理
- 需要排查前端请求、渲染、交互或状态同步问题

## 关注重点

- 页面信息架构是否清晰
- 组件是否可复用
- 表单校验和错误提示是否完整
- 状态管理是否简单、可维护
- API 请求是否统一封装
- 权限菜单和页面访问是否一致

## 推荐工作流

1. 确认入口页面和目标用户
2. 梳理数据来源和交互流程
3. 设计组件拆分方案
4. 实现页面、状态与请求
5. 补充空态、加载态、错误态
6. 核对路由、权限、导出、预览等边界

## 实现原则

- 优先复用已有组件与样式规范
- 尽量将业务逻辑与视图逻辑分离
- 网络请求统一走封装层
- 避免在页面中堆积过多硬编码
- 对复杂页面提供最小注释和结构说明

## 验收清单

- 页面可访问
- 关键操作可闭环
- 表单校验正常
- 列表、详情、编辑、删除流程一致
- 权限与菜单展示一致
- 文案、状态、异常提示可读
